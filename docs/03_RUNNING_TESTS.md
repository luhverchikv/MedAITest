# Запуск тестов

## Обзор

`run_test.py` — CLI-инструмент для запуска AI-моделей на тестах.

```bash
python run_test.py [опции]
```

## Быстрый старт

```bash
# Запуск теста по ID
python run_test.py --test-id 1

# С указанием модели
python run_test.py --test-id 1 -m gemini-2.5-flash-lite

# Ограничить количество вопросов
python run_test.py --test-id 1 -n 50
```

## Опции команды

| Опция | Описание | Пример |
|-------|----------|--------|
| `--test-id <id>` | ID теста | `--test-id 1` |
| `--test-name <name>` | Имя теста | `--test-name "Emergency"` |
| `--list-tests` | Показать список тестов | `--list-tests` |
| `-m <model>` | Модель AI | `-m gemini-2.5-flash-lite` |
| `-n <num>` | Количество вопросов | `-n 100` |
| `-t <temp>` | Температура (0.0-1.0) | `-t 0.5` |

## Доступные модели

Модели настраиваются в `config.py`:

```python
MODELS_TO_TEST = [
    {"name": "gemma-3-27b-it:free", "display_name": "Gemma 3 27B (Free)"},
    {"name": "gemini-2.5-flash-lite", "display_name": "Gemini 2.5 Flash Lite"},
    {"name": "gpt-5-nano", "display_name": "GPT-5 Nano"},
    {"name": "gemini-2.5-pro", "display_name": "Gemini 2.5 Pro"},
]
```

### Бесплатные модели

| Модель | Описание |
|--------|----------|
| `gemma-3-27b-it:free` | Gemma 3 27B (рекомендуется для тестов) |
| `gemini-2.5-flash-lite` | Быстрая и экономная |

### Платные модели

| Модель | Провайдер |
|--------|-----------|
| `gpt-5-nano` | OpenAI |
| `gpt-5-mini` | OpenAI |
| `gemini-2.5-pro` | Google |
| `llama-4-maverick` | various |

## Примеры использования

### Интерактивный выбор

```bash
python run_test.py
# Программа покажет меню выбора теста и модели
```

### Тестирование бесплатной моделью

```bash
python run_test.py --test-id 1 -m gemma-3-27b-it:free
```

### Тестирование определённого количества вопросов

```bash
# Только 50 вопросов
python run_test.py --test-id 1 -n 50
```

### Смена модели

```bash
python run_test.py --test-id 1 -m gemini-2.5-pro
```

## Сохранение прогресса

Прогресс сохраняется автоматически каждые 10 вопросов. При прерывании теста можно продолжить.

### Продолжить прерванный тест

```bash
# Просто запустите заново — незавершённые вопросы будут пропущены
python run_test.py --test-id 1
```

## Настройки

В файле `config.py`:

```python
# Максимум вопросов (None = все)
MAX_QUESTIONS = None

# Сохранять каждые N вопросов
SAVE_PROGRESS_EVERY = 10

# Задержка между запросами (сек)
REQUEST_DELAY = 0.5

# Температура генерации
TEMPERATURE = 0.3

# Максимум токенов в ответе
MAX_TOKENS = 100
```

## Логи

Все запуски сохраняются в папке `logs/`:

```
logs/
├── run_1.log
├── run_2.log
└── run_3.log
```

## Устранение проблем

### "Model not found"

```bash
# Проверьте доступные модели
python run_test.py --list-tests
```

### "API key not set"

```bash
# Установите API ключ в .env
echo "VEDAI_API_KEY=your_key" >> .env
```

### "Too many requests"

```bash
# Увеличьте задержку в config.py
REQUEST_DELAY = 2.0  # 2 секунды
```
