# 🔍 Модуль поиска подозрительных вопросов

## Установка

1. **Скопируйте файлы в проект:**
   - `find_bad_questions.py` — новый модуль
   - `database.py` — обновлённый (добавлены новые функции)

2. **Или скопируйте весь проект** из репозитория

## Быстрый старт

### 1. Запустите тесты с разными моделями

```bash
python run_test.py -m gemma-3-27b-it:free -n 100  # Запуск #1
python run_test.py -m gemini-2.5-flash-lite -n 100  # Запуск #2
python run_test.py -m gpt-5-nano -n 100  # Запуск #3
```

### 2. Найдите подозрительные вопросы

```bash
python find_bad_questions.py 1 2 3
```

### 3. Проверьте найденные вопросы

```bash
# Детальный анализ конкретного вопроса
python find_bad_questions.py --detail 42 --runs 1 2 3
```

## Параметры команды

| Параметр | Описание | Пример |
|----------|----------|--------|
| `run_ids` | ID запусков для сравнения | `1 2 3 7` |
| `-t` | Порог согласия (0.0-1.0) | `-t 0.5` |
| `--min-models` | Мин. количество моделей | `--min-models 3` |
| `--json` | Файл для экспорта | `--json result.json` |
| `--detail` | ID вопроса для анализа | `--detail 42` |
| `--runs` | ID запусков для анализа | `--runs 1 2 3` |

## Примеры использования

### Базовое сравнение (все модели должны дать одинаковый ответ)

```bash
python find_bad_questions.py 1 2 3
```

### Сниженный порог (50% моделей дали одинаковый ответ)

```bash
python find_bad_questions.py 1 2 3 4 5 -t 0.5
```

### Минимум 3 модели с одинаковым ответом

```bash
python find_bad_questions.py 1 2 3 4 5 --min-models 3
```

### Экспорт в JSON для отчёта

```bash
python find_bad_questions.py 1 2 3 --json suspicious_questions.json
```

### Детальный анализ конкретного вопроса

```bash
python find_bad_questions.py --detail 42 --runs 1 2 3 4 5
```


### Степень серьёзности

- 🚨 **4+ модели** — высокая вероятность проблемы с вопросом
- ⚠️ **3 модели** — стоит проверить формулировку
- 📌 **2 модели** — возможно совпадение, но стоит обратить внимание

## Гипотеза

> Если разные модели ИИ (с разной архитектурой и обучающими данными) дают одинаковый НЕПРАВИЛЬНЫЙ ответ на вопрос, это может указывать на:
>
> 1. **Двусмысленность формулировки** — вопрос можно понять по-разному
> 2. **Неочевидный "правильный" ответ** — составитель теста мог ошибаться
> 3. **Устаревшие данные** — в новых исследованиях ответ мог измениться
> 4. **Ошибку в тесте** — неправильно указан правильный ответ

## Рекомендации

1. **Используйте 3+ модели** для надёжности
2. **Проверяйте вручную** все найденные вопросы
3. **Ведите журнал** найденных проблем
4. **Обновляйте тесты** при обнаружении ошибок
